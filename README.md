# Bureau — suite bureautique dans le navigateur

Traitement de texte, tableur et présentations sur une seule page, sans installation.

- **Texte** : mise en forme, listes, titres, tableaux, images, liens, rechercher/remplacer. Export .docx, .html, .txt
- **Tableur** : formules (SOMME, SI, RECHERCHEV, NB.SI…), recopie, tri, graphiques, plusieurs feuilles. Export .xlsx, .csv
- **Présentation** : thèmes, formes, images, notes, mode diaporama (F5). Export .pptx
- **Word** : en-têtes et pieds de page, numéros de page, table des matières, commentaires, changement de casse, impression/PDF
- **Excel** : figer les volets, fusion, filtres, mise en forme conditionnelle, fonctions financières (VPM, VAN, TRI…), export .xlsx avec couleurs
- **PowerPoint** : transitions, animations, tableaux, lignes et flèches, rotation, sélection multiple et alignement
- **Partout** : mode sombre, raccourcis clavier, version mobile
- **Ouvrir** : .docx, .xlsx, .xls, .csv, .pptx, .pdf (lecture + conversion en document)

Les fichiers sont enregistrés automatiquement dans le navigateur (localStorage).

## Installer comme une application

Ouvre https://ozne26.github.io/bureau/ dans Google Chrome puis clique sur **Installer** (en haut de la page) ou sur l'icône d'installation dans la barre d'adresse. Bureau s'ouvre alors dans sa propre fenêtre, fonctionne hors connexion et peut ouvrir directement les fichiers .docx, .xlsx, .pptx, .csv et .pdf.
